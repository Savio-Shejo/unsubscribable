# 📓 Project Journal — UNSUBSCRIBABLE

Build log for the project-journal side quest. Timestamps are venue time, vibes are accurate.

## Hour 0 — Arrival
Idea locked: a newsletter you can never leave. Solo. Vanilla JS, zero backend — if the wifi dies, the demo lives. Forked the starter repo, opened `index.html`, wrote the world's tiniest unsubscribe link.

## Hour 2 — MVP suffering
Cookie Hell + guilt-trip modal + fleeing button working. First playtester (person next to me) said "skill issue" unprompted. That's when we knew.

## Hour 5 — Rage engine
Rage meter, screen shake, red vignette, evil popups whose X button multiplies them. Right-click now costs $9.99/month. Morale: low. Comedy: high.

## Hour 8 — The pity doctrine
Realisation: pure evil is unbeatable, and unbeatable isn't demoable. Added pity everywhere — cookies die after 3 respawns, dodge button tires, password waives its evil rule. Frustrating, never impossible. Beat-able in ~3 min.

## Hour 11 — Juice
Canvas confetti, WebAudio fanfare, level toasts, shuffled content per run (headlines, cookie names, captcha grid). Best-score + victims counter in localStorage.

## Hour 14 — Endings
One ending wasn't enough. Now 3: ZEN (<15 rage), classic SIKE, FERAL (50+ rage → hired as Chief Rage Officer). Finale deploy log: 47 microservices, 312 skipped tests, shipped on a Friday.
